# Aplicativo de Finanças Pessoais

Este é um aplicativo desenvolvido em React Native para gerenciar suas finanças pessoais. O objetivo é fornecer uma interface simples e intuitiva para controlar receitas e despesas, ajudando o usuário a manter um orçamento equilibrado.

## Funcionalidades

- Cadastro de receitas e despesas
- Visualização de saldo atual
- Relatórios diários, semanais e mensais
- Análises gráficas de despesas e receitas

## Tecnologias Utilizadas

- React Native
- Redux para gerenciamento de estado
- React Navigation para roteamento
- AsyncStorage para armazenamento local
- Axios para comunicação com a API

## Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/Thiago-Graciano/Capacitacao-React-Native.git
cd Capacitacao-React-Native
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Inicie o aplicativo

```bash
npm start
```

## Uso

Após iniciar o aplicativo, você pode adicionar receitas e despesas. Utilize a tela de relatórios para visualizar seu histórico financeiro.
